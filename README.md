# MedBridge (Vibe & Build)

A modern, transparent healthcare navigation and health-wealth tracking web application.

## 🚀 Key Features

- **Verified Doctor Specialties**: Select from top specialists (Cardiologists, Dermatologists, Neurologists, Orthopedics, and more) with transparent consultation fees and instant booking.
- **Hyperlocal Medicine Prices Radar**: Compare real-time rates of any medicine across nearby Government Jan Aushadhi Kendras, local chemists, and retail pharmacies with up to 84% savings.
- **Health Wealth & Credit Tracking**: Earn and redeem HealthCredits for medicine discounts and wellness milestones.
- **Emergency SOS & Ambulance Dispatch**: 1-click GPS dispatch with pre-arrival hospital ER bed locking.
- **Peer Health Communities**: Connect with verified recovery journeys and condition-specific groups.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (Responsive & Modern UI)
- **Effects**: Canvas Confetti

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
